# NeuralDamage Frontend

## Package Manager

This project uses **bun** as its package manager. Always use `bun` commands instead of `npm` or `yarn`.

- Install dependencies: `bun install`
- Add a package: `bun add <package>`
- Add a dev dependency: `bun add -D <package>`
- Run scripts: `bun run <script>`

## AI attribution

Do not add AI / Claude attribution anywhere — not in commit messages, PR or issue descriptions, or comments. Never include `Co-Authored-By: Claude`, `🤖 Generated with [Claude Code]`, `_Generated by Claude Code_`, `claude.ai/code` / `claude.com/claude-code` session links, or any mention of AI assistance. This applies to commit author and committer metadata too.
